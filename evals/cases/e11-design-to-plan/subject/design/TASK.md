# Prepare a design candidate

Design JSON Lines export alongside the existing CSV path under CONTRACT.md.
Use the pinned whiteboard template to write `whiteboard.md` and provide the
review-ready design brief. Include applicable KB coverage, clear behavior and
responsibility boundaries, matching architecture/business/data/error views
where useful, and decision inventories required by the workflow.
The owner has requested design work, not accepted a conclusion. Leave the
candidate open for independent review and human acceptance. Do not create an
implementation plan or change the library during this stage.
