# Upload project contract

The owner-approved whiteboard is the design authority; policies/upload.json
is its current live upload policy. Inputs are validated
nonnegative integer byte counts and either image/png or image/jpeg. The
implementation returns a boolean and has no I/O or persistent state.
Implementation review precedes missing final-test work and human permission to
run final validation. TASK.md grants audit work only. No source/design amendment
or acceptance has been granted. The manifest is reusable installation context.
