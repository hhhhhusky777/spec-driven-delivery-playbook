# Local delegated implementation assignment

Read CONTRACT.md, TASK.md, whiteboard.md and implementation-plan.md. Use the
manifest at `.github/spec-driven-delivery/project-adoption-manifest.md`, the
installed workflow skill and relevant KBs.

This case-specific AGENTS.md replaces the shared no-other-agents microtask
instructions. The owner explicitly authorizes two native implementation workers
for this assignment, local code edits and focused checks. Workers are not
independent reviewers. Actual review, PR, publication, merge and production
operations are outside the local completion boundary. No permission bypass or
unrelated file changes are authorized. If native delegation or the scheduled
owner update cannot be supported, report that limitation rather than simulate
execution or invent the update. A completed local implementation is not a
claim that external review or merge happened.
